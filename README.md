# VideoRenda

Aplicativo de vídeos com foco em futura monetização.

## Versão atual
- Feed de vídeos
- Seleção e publicação local de vídeos
- Curtidas
- Perfil
- Carteira inicial
- Estrutura Android via Capacitor

## Rodar no computador
```bash
npm install
npm run dev
```
